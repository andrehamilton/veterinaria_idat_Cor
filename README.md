# HuellitasVet

Sistema de gestión veterinaria desarrollado con Angular.

## Descripción

HuellitasVet permite gestionar la información de las mascotas, organizar citas veterinarias y consultar su historial médico.

## Funcionalidades

- Registro, edición y eliminación de mascotas.
- Agendamiento, edición y eliminación de citas veterinarias.
- Control de horarios ocupados.
- Gestión del historial médico.

## Tecnologías utilizadas

- Angular
- TypeScript
- HTML5
- Bootstrap
- CSS

## Instalación y ejecución

1. Clona o descarga este repositorio y abre la carpeta del proyecto en Visual Studio Code.
2. Instala las dependencias:

   ```bash
   npm install
   ```

3. Inicia el servidor de desarrollo:

   ```bash
   npm start
   ```

   También puedes usar `ng serve` si tienes Angular CLI instalado globalmente.

4. Abre [http://localhost:4200](http://localhost:4200) en el navegador.
